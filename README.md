# Modelagem e Inferência Estatística - UFMS

Repositório destinado aos estudos, anotações e códigos da disciplina **Modelagem e Inferência Estatística** (código 32010005861), componente curricular dos cursos de **Ciência de Dados** e **Inteligência Artificial** da Universidade Federal de Mato Grosso do Sul (UFMS).

## 📚 Ementa Resumida
A disciplina tem como foco o processamento, análise e modelagem de dados, abrangendo os seguintes tópicos principais:
- Revisão de Probabilidade e Variáveis Aleatórias
- Inferência Estatística e Testes de Hipóteses
- Análise de Variância (ANOVA)
- Análise de Regressão Linear Simples e Múltipla
- Modelos Lineares Generalizados (GLM)

## 📖 Bibliografia de Referência

Abaixo estão os livros clássicos recomendados e amplamente utilizados para cobrir a ementa desta disciplina:

1. **BUSSAB, W. O.; MORETTIN, P. A.** *Estatística Básica*. 9ª ed. Saraiva, 2017.
   > *(Excelente para a base estatística, intervalos de confiança e testes de hipóteses).*
2. **CASELLA, G.; BERGER, R. L.** *Inferência Estatística*. Cengage Learning, 2011.
   > *(Referência aprofundada para a parte de inferência teórica).*
3. **MONTGOMERY, D. C.; PECK, E. A.; VINING, G. G.** *Introduction to Linear Regression Analysis*. 5th ed. Wiley, 2012.
   > *(Livro fundamental para os estudos de regressão linear simples e múltipla).*
4. **DOBSON, A. J.; BARNETT, A. G.** *An Introduction to Generalized Linear Models*. 3rd ed. Chapman and Hall/CRC, 2008.
   > *(Principal referência para Modelos Lineares Generalizados - GLM).*
